# Layout gallery

Each layout and variant in the light theme with the built-in tokens. A template or the dark theme changes the colors
and sizes, not the arrangement. The screenshots are generated by `npm run docs:screenshots`; see
[backgrounds](backgrounds.md#screenshots). A slide names a layout as `family` or `family/variant`; see
[schema](schema.md#layout-names).

| Group | Layouts |
| --- | --- |
| [Opening, structure, and ending](layouts-structure.md) | `cover`, `agenda`, `section`, `closing`, `blank` |
| [Text and media](layouts-content.md) | `content`, `two-columns`, `media`, `code` |
| [Cards and panels](layouts-cards.md) | `cards`, `stats`, `panels`, `matrix`, `compare`, `team` |
| [Flows and diagrams](layouts-flow.md) | `process`, `hub`, `timeline`, `gantt` |
| [Tables, charts, and quotes](layouts-data.md) | `table`, `chart`, `quote` |

| Layout | Use it for | Variants |
| --- | --- | --- |
| [`cover`](layouts-structure.md#cover) | The opening slide | `default`, `centered`, `split`, `band` |
| [`agenda`](layouts-structure.md#agenda) | A table of contents with links | `default`, `chapters`, `outline` |
| [`section`](layouts-structure.md#section) | A chapter divider with an automatic number | `default`, `centered`, `band` |
| [`content`](layouts-content.md#content-and-two-columns) | Paragraphs, lists, and images | `default` |
| [`two-columns`](layouts-content.md#content-and-two-columns) | A comparison in two columns | `default` |
| [`media`](layouts-content.md#media) | A picture as the subject | `default`, `right`, `full` |
| [`cards`](layouts-cards.md#cards) | One to six short parallel ideas | `default`, `rounded`, `badge`, `circle`, `hexagon`, `pentagon` |
| [`stats`](layouts-cards.md#stats) | Two to six key figures | `default`, `cards` |
| [`panels`](layouts-cards.md#panels) | Two to seven sections split by lines, with optional colors | `default`, `rows` |
| [`matrix`](layouts-cards.md#matrix) | A 2 × 2 matrix | `default`, `lines` |
| [`compare`](layouts-cards.md#compare) | Two to four options side by side | `default` |
| [`team`](layouts-cards.md#team) | Two to six people | `default` |
| [`process`](layouts-flow.md#process) | Two to six steps in order | `default`, `vertical` |
| [`hub`](layouts-flow.md#hub) | A central idea with items around it | `default` |
| [`timeline`](layouts-flow.md#timeline) | Dated events | `default` |
| [`gantt`](layouts-flow.md#gantt) | A project schedule | `default` |
| [`table`](layouts-data.md#table-and-chart) | A table | `default` |
| [`chart`](layouts-data.md#table-and-chart) | Bars, columns, or a donut | `default`, `columns`, `donut` |
| [`code`](layouts-content.md#code) | A code listing | `default`, `dark` |
| [`quote`](layouts-data.md#quote) | A quotation | `default`, `centered` |
| [`closing`](layouts-structure.md#closing) | The last slide with contacts | `default`, `centered`, `band` |
| [`blank`](layouts-structure.md#blank) | Only a background | `default` |

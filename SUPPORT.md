# Support

Use the repository issue tracker for reproducible defects and feature requests. Include the
SlideForge commit or version, Node.js version, operating system, PowerPoint version if
relevant, the command or API call, and the layout or validation report. Attach a minimal,
nonsensitive presentation JSON where possible. Never attach confidential decks,
credentials, or sensitive full paths.

Security issues must follow [SECURITY.md](SECURITY.md). This pre-release project does not yet
offer a production support SLA.
